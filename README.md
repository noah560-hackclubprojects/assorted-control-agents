# Assorted control agents
This repository contains various
(although I've only made one so far)
in-browser pages that train and run
models that control simulated machines.
The models are trained via neuroevolution,
which uses algorithms that mimic natural
evolution to train neural networks to
perform a task.

## Battle bots/robots
Each "robot" is a circle that can
change its size and push itself
forward and backward. The first
robot to get to the opposite side
of the screen wins.
